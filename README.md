# RecapRawSQL

Repositório dedicado à revisão e prática de **SQL puro**, com foco no básico da construção de consultas, manipulação de dados e domínio dos principais comandos da linguagem.

## Conteúdo

- SELECT - consultas e projeção de dados
- WHERE - filtros e condições
- ORDER BY - ordenação de resultados
- GROUP BY - agrupamento de dados
- HAVING - filtros sobre agrupamentos
- JOINs - relacionamento entre tabelas
- Subqueries - consultas aninhadas
- INSERT - inserção de registros
- UPDATE - atualização de registros
- DELETE - exclusão de registros
- Funções de agregação e funções SQL
- DDL e DML - definição e manipulação de dados

## Objetivo

Consolidar conhecimentos em SQL por meio de exercícios práticos, consultas e resolução de problemas utilizando comandos SQL diretamente, sem depender de ORMs ou abstrações.
